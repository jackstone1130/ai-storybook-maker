# ai-storybook-maker

把一个故事文本，做成**会动、会念、能指读**的绘本 —— 输出是**一个 HTML 文件**，双击就能用。

给自家孩子做的，顺手整理成技能包放出来。

---

## 做出来是什么样

```
每一格 = AI 插画 + 大字长句 + 绿框跟说句 + 家长提示
```

**家长读**：小兔子先走到洗手台，把两只小手洗得干干净净。　← 练「听长句」
**↳ 孩子说**：小兔子先洗手。　　　　　　　　　　　　← 练「开口」

> 长句和短句是**分开**的：长句练听、短句练说，**不要求孩子复述长句**。这是整套设计的核心。

功能：

| | |
|---|---|
| **逐字指读** | 念到哪个字，哪个字亮（长句橙底 / 跟说句绿底） |
| **两段式朗读** | 先念完整长句，再念一句短的让孩子跟说 |
| **持续听** | 依次播各页长句，边播边翻页边高亮 |
| **推拉镜头** | 插画缓慢放大平移，静态图也不呆板 |
| **单文件** | 图片音频全部内嵌，拷到哪都能用，离线可播 |
| **可打印** | 展开全部画面 → 浏览器打印 → 装订成册 |
| **防乱点** | 按钮默认全隐藏，长按画面 1.2 秒唤出 |

## 用法

技能会引导走完六步：**设计文本 → 生成插画 → 图片后处理 → 生成朗读 → 组装 HTML → 验证**。

三个脚本可以单独用：

```bash
# 1) 插画后处理：备份原图 → 去水印 → 压缩
python3 scripts/prep_images.py 插画样片/s1_小兔子 插画样片/s2_小熊

# 2) 生成朗读音频并内嵌回 HTML（改音色/语速后重跑即可）
python3 scripts/make_tts.py 绘本.html

# 3) 无头浏览器诊断（交付前必跑）
python3 scripts/check_page.py 绘本.html 6 5
```

脚本头部都有可调常量（音色、语速、水印坐标、目标尺寸）。

## 几条硬性约定

都是踩坑换来的，细节见 [`references/pitfalls.md`](references/pitfalls.md)。

1. **单文件自包含** —— 预览类服务通常只映射单个 HTML，同目录资源一律 404
2. **面向浏览器直接打开设计** —— 预览面板往往不出声
3. **播放失败必须显式提示** —— 静默降级会让用户以为是内容问题，排查绕好几轮
4. **长句 / 跟说句拆成两段音频** —— 否则逐字高亮对不准
5. **不要用 `say` 的 `[[pbas]]`** —— 它是整体升降调而非语调曲线，会让人声发飘
6. **`transform: scale()` 的父容器必须 `overflow:hidden`** —— 否则放大的图压到文字
7. **替换大段代码别用远处锚点** —— 中间夹着的代码会被静默删掉，页面变白板
8. **改完必跑无头诊断** —— 语法通过 ≠ 能跑
